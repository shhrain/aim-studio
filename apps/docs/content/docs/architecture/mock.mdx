## 设计

- 业务契约在 `@aim/api-contracts`；`@aim/api-client` 负责发起请求。下面列出的是 Mock 仍覆盖的旧体验路径，便于对照组件测试：
- `@aim/mock` 基于契约实现 MSW handlers，并复用 `@aim/template-core` 的预检、转换逻辑，行为与真实后端一致；
- 同一套 handlers 用于浏览器（Service Worker）、Vitest（`msw/node`）、Storybook 与 Playwright；
- 浏览器只在 HTTPS / `localhost` 下允许 Service Worker。`startMockWorker()` 在非安全上下文（如 Docker 部署后通过 `http://内网IP` 访问）会自动降级为**页面内 fetch 拦截**（`getResponse(handlers, request)`），未命中的请求原样透传；因此业务代码中的 Mock 接口请求统一走 `fetch`（如验证码图片先 `fetch` 再转为 blob URL）。

## 响应格式

```json
{
  "subCode": 0,
  "message": "success",
  "data": {},
  "pageInfo": { "total": 18, "pageIndex": 0, "pageSize": 8 }
}
```

| subCode     | 含义            | 前端处理                          |
| ----------- | --------------- | --------------------------------- |
| 0           | 成功            | –                                 |
| 1001        | 参数错误        | 提示                              |
| 1002        | 验证码错误      | 刷新验证码                        |
| 1003        | 频率限制        | 提示稍后再试                      |
| 2001 / 2002 | 不存在 / 已存在 | 提示                              |
| 3001 / 3002 | 上游异常 / 超时 | 提示                              |
| 5000        | 系统异常        | 提示，可重试                      |
| 9001        | 登录失效        | 清除登录态，跳转 `/auth-required` |

## 接口清单

**移动端**（前缀 `/rcs/aim-experience/api/v1`）：`auth/image-code`、`template/filter-options`、`template/list`、`template/detail`、`send/preview`、`send/experience`、`send/detail`、`send/recent`、`send/statistics`、`ability/query`、`contacts/page`、`contacts`（POST / PUT / DELETE）、`wechat/signature`。

**编辑器**（前缀 `/api/editor/v1`）：`templates`（CRUD、duplicate、submit）、`materials`、`precheck/deep`、`tools/link-check`、`ai/copywriting`、`feedback`。

**扫码预览**：移动端 Route Handler `POST /api/share`、`GET /api/share/:id`（进程内存，30 分钟过期）。

## 切换真实后端

```bash
# apps/*/.env.local
NEXT_PUBLIC_API_MOCK=false
NEXT_PUBLIC_API_BASE=https://api.example.com
```

业务代码只依赖 `@aim/api-client`，无需修改。
