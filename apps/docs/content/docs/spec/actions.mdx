## 校验规则

- 链接字段必须以 `https://` 开头，长度不超过 3000；
- 电话字段允许数字、`*`、`+`、`-`、空格（3–20 位），可使用参数；
- 日程的结束时间必须晚于开始时间；
- 打开 APP / 快应用可配置兜底类型：应用市场、快应用、直接打开 H5、外部浏览器打开 H5。
