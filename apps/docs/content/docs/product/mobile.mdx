## 页面一览

| -------------------------- | ---------- | ------------------------------------------------------------- |
| `/`                        | 首页       | 模板发送、扫码体验、能力查询、三信融合四个入口                |

## 登录态

`proxy.ts` 读取 URL 中的 `token` / `phone`（兼容 `loginPhone`），写入 Cookie 后重定向到干净地址；接口请求头携带 `AuthorizationCode`，`subCode = 9001` 时清除登录态并跳转 `/auth-required`。

## 测试发送

1. 输入号码或从通讯录选择（每次最多 10 个）；
2. 选择发送方式：融合优先（阅信 → 5G 消息 → 视频短信自动降级）或定向发送；
3. 预览每个号码的可达形态，可单独切换；
4. 输入图形验证码后提交。含动态参数的模板仅可预览，不可体验发送。

## 适配方案

- **流式 rem**：`html { font-size: clamp(14px, 100vw / 375 × 16, 20px) }`，Tailwind 的 rem 单位随屏宽线性缩放，无需 JS 或 px2rem 插件；
- **安全区**：顶栏、底栏、底部抽屉均处理 `env(safe-area-inset-*)`，视口启用 `viewport-fit=cover`；
- **预览**：使用 SDK 的 `fluid` / `thumbnail` 模式，与编辑器同一套渲染；
- **微信**：在微信内置浏览器中按需加载 JS-SDK 配置分享卡片，失败时静默降级。
