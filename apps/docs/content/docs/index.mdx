## 什么是 5G 阅信

5G 阅信（Advanced Intelligent Message，AIM）是由手机厂商系统短信能力渲染的富媒体消息：企业在一条短信中下发图文、视频、卡券、通知等卡片，用户点击即可直达服务。

同一份模板可通过 **三信融合** 同时下发：

| 终端                                    | 协议         | 说明                 |
| --------------------------------------- | ------------ | -------------------- |
| 安卓（华为、荣耀、小米、vivo、OPPO 等） | AIM 阅信     | 厂商系统短信渲染卡片 |
| 苹果                                    | RCS 5G 消息  | 运营商 5G 消息卡片   |
| 其他终端                                | RMS 视频短信 | 图文帧序列           |

## 核心原则

- **一份协议，多端复用**：`@aim/template-schema` 定义模板文档，编辑器、移动端、服务端共用。
- **预览即真机**：`@aim/template-preview` 以容器单位等比渲染，PC 手机壳、移动端全宽、列表缩略图表现一致。
- **规范即代码**：版式字数限制、厂商矩阵、事件降级规则写在 schema 中，文档与 AI 提示词由它自动生成。
- **工作空间隔离**：账号、模板、素材和发送任务按工作空间持久化；服务端不信任客户端传入的租户或审核状态。
- **Mock 仅用于演示**：正式流程走 `@aim/api`。`@aim/mock` 只留给组件开发、测试和显式演示。
