## 产品入口

`apps/web` 是主站、账号页面和业务控制台。`/{locale}` 展示产品与文档入口；注册并验证邮箱后进入 `/{locale}/app` 创建或选择工作空间。`locale` 支持 `zh-CN`、`en`。模板创作地址为 `/{locale}/app/w/{workspaceId}/create/{id}`，旧 `/editor/{id}` 经服务端成员校验后跳转。

独立应用 `apps/mobile` 位于 `/m`，共享主站 HttpOnly Cookie，只展示当前工作空间已发布的版本。文档站独立部署，地址由 `NEXT_PUBLIC_DOCS_URL` 统一提供。`apps/api` 同时输出 HTTP 服务和独立 worker 入口。

## 账号与团队

邮箱密码注册必须完成邮箱验证。忘记密码后通过一次性链接重置，旧会话立即失效。个人设置提供资料、邮箱变更、密码修改、时区、会话撤销。工作空间可创建多个，URL 中的工作空间 ID 是每个标签页的独立作用域。

- 所有者：全部业务、团队与所有权转移。
- 管理员：业务和成员管理，不能操作所有者或转移所有权。
- 编辑者：模板、素材、提交审核和发送任务。
- 审核者：查看、审核、发布与下架。
- 查看者：只读，联系人号码脱敏，不可创建公开分享。

邀请链接绑定指定邮箱、有效期和目标角色；必须用该邮箱登录接受。移除或降级成员立即作用于后续请求；最后一个所有者受到保护。客户端角色仅控制可见入口，服务端每次请求重新验证成员身份。

## 模板生命周期

创建和导入均成为草稿。保存必须携带 `revision`，版本冲突返回 HTTP 409，并保留本地编辑以便导出。客户端保存串行执行，保存期间的新编辑继续排队；恢复副本按用户、工作空间和模板隔离，退出时清理。

提交审核时服务端重新执行 Schema 校验、富文本净化、预检和协议转换，创建不可变版本快照。审核通过不自动发布；发布明确绑定已通过的版本。后续修改生成新草稿，不改变已发布内容。归档前必须先下架、退出审核状态。

本期审核是工作空间内部审核，不代表厂商批准。个人工作空间的所有者可审核自己的模板，操作进入审计日志。

## 文件与分享

文件经过实际类型、字节大小和媒体元信息检查，图片限制解码像素，音视频通过 ffprobe 禁止远程协议后解析。存储支持持久卷或私有 S3。授权文件接口支持单段 HTTP Range；未登录或非成员无法读取。

有效模板版本和分享使用的素材不能直接删除。分享令牌高熵随机，数据库保存摘要，默认 30 分钟过期，可以提前撤销；匿名访问只获得快照及其中引用的素材。

## 任务与通道

pg-boss 提供持久队列，事务 outbox 避免数据库提交与入队之间丢任务。尝试次数保存在 outbox，失败采用指数退避，五次后标记失败；允许权限范围内重试本地预检和模拟任务。

发送请求需 `Idempotency-Key`；同键同请求复用任务，同键不同请求返回 409。模拟记录保存 `mode: simulated`，界面明确提示没有真实消息发送。生产禁止模拟；未配置供应商时能力明确禁用。

扩展发送适配器时，必须增加供应商请求幂等、回执验签、事件去重、乱序合并和不确定结果核对流程。不得把受理当送达，不得将真实通道接到模拟成功状态分支。AI 只返回候选文案，用户主动应用。

## API 和错误

业务路由 `/api/v1/*` 使用 `subCode/message/data`，HTTP 状态与业务错误一致。认证 `/api/auth/*` 保留 Better Auth 协议。可机读接口目录为 `/api/openapi.json`；应用统一通过 `@aim/api-client` 调用，禁止业务组件散落 fetch。

常用错误：1001 输入错误、2002 版本或状态冲突、3001 能力不可用、9001 未登录、9003 无权限、2001 资源不存在、1003 限流、5000 服务异常。客户端应使用稳定错误码和 HTTP 状态，不能依赖中文字符串判断逻辑。

租户记录、关联文件和所有列表查询都必须验证工作空间。客户端 `whois`、创建者、审核状态和预检通过标记不能授权或改变服务端状态。用户数据使用 no-store，SSR 转发 Cookie 到内部 API，不进入公共缓存。

## 主题、语言与设备

主站支持浅色、深色、跟随系统。偏好保存账号并保留本机设置；厂商预览独立控制皮肤，控制台主题不能改变输出。中英文通过公共词典和 next-intl 路由接入；模板正文、素材名和参数名保持用户原文。

大屏使用侧栏与主辅布局，平板使用折叠面板，手机使用结构化字段、参数和完整预览。手机不提供自由画布的位置尺寸编辑。表格仅局部横滑，弹层通过 Radix 管理焦点与滚动。适配验收应覆盖 360、390、768、1024、1280、1440、1920px，短屏和 200% 缩放。

## 开发与验证

```bash
pnpm install
pnpm db:generate
pnpm db:migrate
pnpm dev:api
pnpm --filter @aim/api worker
pnpm dev:web
pnpm dev:mobile
pnpm --filter @aim/api test:integration
pnpm typecheck
pnpm lint
pnpm test
pnpm test:e2e
```

开发前设置 DATABASE_URL、BETTER_AUTH_SECRET、PUBLIC_URL 和 SMTP 等服务端环境变量。测试使用独立真实 PostgreSQL 17，不替换为 SQLite。测试临时数据库和随机凭据仅位于 `.cache`，不要用于生产。

默认 `NEXT_PUBLIC_API_MOCK=false`。Mock 只用于独立组件和显式演示，不再支持 URL token 登录。旧 Mock 数据需显式导出、登录后导入；原审核和发送状态不会继承，私有素材需要重新上传。
