## 语法

- 编辑器与文档内使用 `{#参数名#}`，例如 `尊敬的{#姓名#}`；
- 导出 RCS / RMS 协议时转换为 `${参数名}`；
- 参数名仅支持中英文、数字、下划线，最多 30 个字符；
- 同名参数合并为一个定义。

## 校验

- 文档中使用的参数必须已定义且有示例；
- 示例长度需在最小 / 最大长度之间；
- 字数校验按示例值替换后计算。
