## 全宽模式

```tsx
<TemplatePreview document={doc} mode="fluid" interactive="native" paramDisplay="example" />
```

`fluid` 模式不绘制手机壳，卡片铺满容器宽度并带聊天背景与消息时间。配合容器单位，无论 320px 还是平板宽度都能等比呈现。

## 交互

`native` 模式下点击事件会被真实执行：

| 事件 | 行为 |
| --- | --- |
| 打开链接 / 浏览器 / 浮窗 | `window.open` |
| 打开快应用 | 转换为 `https://hapjs.org/` 链接 |
| 拨打电话 / 发送短信 / 邮件 | `tel:` / `sms:` / `mailto:` |
| 复制内容 | 复制到剪贴板并提示 |
| 打开弹窗 | 预览内弹窗 |
| 查看大图 | 预览内全屏大图 |
| 打开地图 | 高德地图 URI |

轮播、横滑、图片选项均支持触控滑动；音视频在点击后播放。

## 与 rem 方案共存

预览内部只使用自身的 `--u` 单位，不受页面根字号影响，可放心与 rem / vw 适配方案共存。
