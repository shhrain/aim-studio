## 配置

Monorepo 内的包直接导出 TypeScript 源码，在 `next.config.ts` 中声明转译：

```ts
const config = {
  transpilePackages: ['@aim/template-preview', '@aim/template-core', '@aim/template-schema', '@aim/utils'],
}
```

在根布局的全局 CSS 中引入样式：

```css
@import '@aim/template-preview/styles.css';
```

发布到 npm 后的包输出 ESM + `.d.ts`，无需转译。

## SSR

- 组件带 `'use client'`，可在服务端组件中直接渲染（会在服务端输出 HTML）；
- 富文本净化为确定性实现，服务端与浏览器输出一致，不会产生水合差异；
- 视频、音频仅在用户点击后才创建播放器。

```tsx
// app/templates/[id]/page.tsx（服务端组件）
import { TemplatePreview } from '@aim/template-preview'

export default async function Page({ params }) {
  const doc = await getTemplate((await params).id)
  return <TemplatePreview document={doc} mode="fluid" paramDisplay="example" />
}
```
