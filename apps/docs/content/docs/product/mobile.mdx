## 入口与登录

统一从主站的 `/m` 进入，包括本机开发和 Docker 部署。独立开发服务的直接地址为 `http://localhost:3001/m`，日常使用主站同源地址，避免 API 和 Cookie 来源不一致。

移动端与主站共用 HttpOnly Cookie。未登录时回到主站邮箱登录页，验证邮箱后恢复目标页面。URL 中的 token 或 phone 不授予登录身份。

工作空间选择按标签页保存，URL 可用 workspace 参数明确指定。切换时清理当前空间缓存与发送草稿，服务端重新验证成员身份。

## 可用页面

- `/m/`：首页与主要操作入口。
- `/m/template-list`：已发布模板、筛选与加载更多。
- `/m/detail?tplId=…`：AIM、RCS、RMS 预览与厂商切换。
- `/m/send-objects`：联系人管理；选择模式最多选择十个号码。
- `/m/send-records`：处理记录，按发送时版本预览历史消息。
- `/m/send-records/statistics`：按所选范围汇总记录；模拟数据明确标识。
- `/m/ability-query`：能力查询，通道未启用时明确提示。
- `/m/scan-experience`：扫码打开工作空间模板列表。
- `/m/preview/{token}`：匿名分享快照，默认三十分钟有效，可提前撤销。
- `/m/embed`：公共预览嵌入接收端。

## 模拟任务边界

本期可使用显式开启的本地模拟适配器，任务不会向号码发送真实短信。生产环境禁止模拟通道；真实供应商未配置时禁用发送与能力查询。

输入一至十个有效号码，选择消息形态后创建任务。重复请求使用相同幂等键，避免重复创建。受理只表示任务已进入队列，最终处理结果在记录中查看。

动态参数模板本期支持预览，不支持直接体验发送。界面提供原因提示，不会自动用示例参数替用户发送。

扫码页面不会要求关注服务号或承诺收到真实消息。微信签名未配置时不加载相关能力。

## 设备与预览

移动端采用结构化表单与响应式页面，处理安全区、软键盘和弹层滚动。手机可编辑模板内容与参数、查看完整预览；自由画布的位置和尺寸在桌面或平板调整。审核中的模板保持只读。

预览使用公共 SDK，厂商皮肤独立于工作台主题。分享失效后无法重新获取快照或素材；已下载到终端的内容无法远程清除。
