## 质量分

编辑过程中模板会被实时预检，顶栏显示 0–100 的质量分：每个错误扣 12 分、每个警告扣 4 分。存在错误时不可提交。

## 快速检测规则

| 规则 | 级别 | 说明 |
| --- | --- | --- |
| 模板名称 | 错误 | 必填，最多 20 字 |
| 发送厂商 | 错误 | 至少一个，且必须是版式支持的厂商 |
| 槽位必填 / 字数 | 错误 | 按版式槽位定义，参数按示例值计算 |
| 默认文案 / 占位图 | 警告 / 错误 | 仍为“编辑文本”或默认插图 |
| 点击事件 | 错误 | 必填字段、链接需 `https://`、长度 ≤ 3000、电话 / 邮箱格式 |
| 参数 | 错误 | 已使用但未定义、缺少示例、示例长度不在范围内 |
| 苹果端兼容 | 警告 | 事件在 RCS 不支持，提交时需补填替代链接 |
| 极限词 | 警告 | 广告法敏感词（可通过插件替换词库） |

## 深度检测

模拟服务端异步检测（约 4 秒）：图片质量、链接可达性、文案合规、加载性能四个维度评分。深度检测出现错误时同样不可提交。

## 三信融合确认

对支持三信融合的版式，提交前会生成 RCS 与 RMS 协议：

- 苹果端不支持的按钮事件（复制、短信、邮件、日程、弹窗）需补填 `https://` 替代链接；
- 红包类模板会生成审核图；
- 视频短信标题取自首个标题文本，动态参数会被剔除。

## 审核流程

用户提交 → 初审 → 运营商审核 → 厂商审核。各厂商审核时效不同，华为支持加急（1–2 小时），荣耀、小米、vivo、OPPO 免审。审核中的模板为只读状态。
