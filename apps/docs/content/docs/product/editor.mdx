## 工作台

「我的模板」按状态（草稿 / 审核中 / 已通过 / 已驳回）与分类（服务类 / 通知类）筛选，支持搜索、预览、复制与删除。被驳回的模板会直接展示驳回原因。

## 新建模板

点击「新建模板」进入版式画廊：按服务类 / 通知类分组展示 33 种标准版式与 1 种自由版式，卡片即为实时渲染的预览。带「三信融合」标记的版式可同时下发 AIM、5G 消息与视频短信。

## 编辑界面

| 区域       | 能力                                                                                                              |
| ---------- | ----------------------------------------------------------------------------------------------------------------- |
| 顶栏       | 模板名称行内编辑、审核状态、自动保存状态、质量分（实时预检）、预览、提交审核                                      |
| 左侧工具栏 | **版式**（字段规范、更换版式）、**元素**（32 种元素）、**素材**（图片 / 视频 / 音频库与上传）、**参数**、**图层** |
| 画布       | 手机壳所见即所得；切换厂商皮肤与参数显示（参数名 / 示例值）；缩放；撤销 / 重做                                    |
| 属性面板   | 内容 / 样式 / 交互三个页签；字数计数、插入参数、AI 文案；未选中元素时为模板设置                                   |

### 画布操作

- 单击选中元素，双击文本直接编辑；
- 结构化版式按厂商规范自动排版，文本高度随内容变化；
- 自由排版下支持拖拽移动、八向缩放、边缘与中线吸附、方向键微调（Shift 步长 10）；
- 有问题的元素以红色虚线标记，点击即可在属性面板看到原因。

### 快捷键

| 快捷键                                | 操作                             |
| ------------------------------------- | -------------------------------- |
| `Ctrl` + `K`                          | 命令面板                         |
| `Ctrl` + `S`                          | 立即保存                         |
| `Ctrl` + `P`                          | 多厂商预览                       |
| `Ctrl` + `Z` / `Ctrl` + `Shift` + `Z` | 撤销 / 重做                      |
| `Ctrl` + `D`                          | 复制元素（自由排版）             |
| `Delete`                              | 删除元素（自由排版或非槽位元素） |
| `Esc`                                 | 取消选中                         |

## 参数

在文本、链接、电话等字段中点击「插入参数」，以 `{#参数名#}` 形式写入。参数在「参数」面板维护类型、示例与长度范围：

- 审核按 **参数示例** 计算字数，请填写真实格式的示例；
- 重命名参数会同步替换模板中所有占位；
- 同名参数自动合并到第一个定义。

## 点击事件

按钮、图片、热区等可配置 15 种点击事件（打开链接、打开 APP、快应用、拨打电话、复制、日程、弹窗等）。每种事件都标注了苹果端（RCS）的支持情况，详见 [点击事件规范](/docs/spec/actions)。

## AI 文案

文本输入框旁的「AI」按钮根据场景描述生成候选文案，自动遵守字段字数上限。Mock 环境为规则生成，可在 `@aim/api-client` 中替换为真实大模型服务。

## 预览

- **多厂商**：并排展示各厂商真机效果，每台手机附扫码二维码；
- **三信融合**：安卓 / 苹果 / 其他终端效果对比；
- **交互体验**：点击预览中的元素，查看触发的事件与参数；
- **数据**：查看 / 复制 / 下载模板文档、RCS tplContent、RMS content、旧版 pages。
